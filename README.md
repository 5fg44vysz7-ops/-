# 우리 집 살림 · 부부 공동 가계부 (웹앱)

매달 저축 · 고정지출 · 자동이체 · 대출 상환을 한 화면에서 보는 부부 공동 가계부입니다.
HTML 파일 하나로 동작하고, 입력한 내용은 **이 기기의 브라우저(localStorage)** 에 먼저 저장됩니다.
**부부 실시간 동기화**를 켜면 두 분 폰이 같은 방을 구독해 서로의 수정을 바로 주고받습니다(켜지 않으면 서버로 나가지 않습니다).

## 아이폰에서 앱처럼 쓰기

1. 아이폰 **사파리**로 이 페이지를 엽니다.
2. 아래쪽 **공유(⬆️) 버튼** → **홈 화면에 추가**를 누릅니다.
3. 이름이 `우리 집 살림`으로 나오는지 확인하고 **추가**를 누릅니다.

홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 뜹니다. 한 번 열어 두면 비행기 모드처럼
네트워크가 없어도 열립니다(서비스 워커가 파일을 기기에 캐시).

## 가계부 데이터 불러오기 / 내보내기

- **고정지출** 탭 맨 아래 `가계부 데이터` 카드에서
  - **불러오기**: `.json` 파일을 골라 지금 이 기기의 가계부를 한 번에 채웁니다.
  - **내보내기**: 지금 상태를 `.json` 파일로 저장합니다(백업·기기 이동용).
- 처음 열면 `한눈에` 화면 위에 `가계부 데이터 불러오기` 카드가 보입니다.
- 빈 화면에서 시작하므로, 쓰던 가계부가 있다면 내보낸 파일을 그대로 불러오면 됩니다.
- 입금(수입) 내역은 `한눈에` 탭 첫 카드의 **+ 입금 추가**로 넣습니다(입금 내역 목록은 `자세한 내역 · 설정 더보기` 안). 처음에는 비어 있고, 넣는 만큼 여윳돈이 계산됩니다.

## 부부 실시간 동기화 (선택)

1. 위쪽 상태 배지(`이 기기에만 저장`)나 **한눈에** 탭의 `자세한 내역 · 설정 더보기` 안에 있는 `부부 실시간 동기화` 카드를 누릅니다.
2. 두 분이 정한 **우리 집 방 코드(6자 이상)** 를 넣고 `실시간 연결`을 누릅니다. 두 폰에 같은 코드를 넣으면 끝입니다(띄어쓰기·대소문자는 구분하지 않음).
3. 방이 비어 있으면 이 폰의 가계부를 올리고, 방에 먼저 가계부가 있으면 받아옵니다. 양쪽 내용이 다르면 `서버 내용 불러오기` / `내 폰 내용 올리기` 중에서 고릅니다.
4. 상태가 `● 실시간 동기화 중`이면, 한쪽에서 추가·수정·삭제한 내용이 다른 폰에 바로 반영됩니다. `동기화 대기(오프라인)`이면 연결되면 자동으로 다시 맞춥니다.
5. 상대방이 새 내역을 올리면 화면 위쪽에 **알림 배너**가 떠서 무엇이 바뀌었는지 보여 줍니다(예: `🔔 상대방이 새 지출을 기록했어요 · 스타벅스 5,000원`). `×`를 누르면 바로 닫히고, 8초 뒤에는 저절로 사라집니다. 앱을 닫아 둔 사이 올라온 내역은 다시 열 때 `🔔 서버의 가계부 내역을 불러왔어요`로 알려 줍니다. 잠금화면 푸시는 아이폰 웹앱 구조상 보내지 않습니다.
6. `[연결 끊기]`로 언제든 이 기기 전용으로 돌아갈 수 있습니다(그 폰의 가계부는 그대로 남음).

- 방 코드는 앱에 들어 있지 않고, 서버에는 코드의 SHA-256 해시만 문서 ID로 갑니다.
- 다만 방 코드를 아는 사람은 그 가계부를 읽고 고칠 수 있습니다. 두 분만 아는 코드를 쓰고 다른 곳에 적어 두지 마세요.
- 같은 순간에 두 폰이 서로 다른 항목을 고치면 마지막 저장이 이깁니다.

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 한눈에 | **첫 화면은 딱 두 카드** — ① 이번 달 생활비(`들어온 돈 − 고정지출 − 고정저축`을 가장 크게, 아래에 들어온 돈·**고정지출**·**고정저축**·쓴 돈·쓴 돈 빼고 남은 돈 5칸, 바로 `+ 지출 기록하기`·`+ 입금 추가` 버튼) — **앞 4칸은 눌러서 상세로 이동**(`들어온 돈 ›` = 더보기 펼침 + 입금 내역으로, `고정지출 ›`·`고정저축 ›`·`쓴 돈 ›` = 해당 탭) ② 이번 달 우리 집(매달 모으는 돈·매달 나가는 돈·지금까지 쓴 돈 3칸, 누르면 해당 탭으로 이동). 나머지 상세는 **`자세한 내역 · 설정 더보기`**(기본 접힘) 안에 있습니다: 입금 내역 추가·수정·삭제, 비율 도넛·막대와 계산 내역, 부부 실시간 동기화, 곳간 기준선 초과분 계산기, 대출 잔액·자동이체·회수금 요약, 데이터 백업 안내 |
| 변동지출 | 빠른 입력, 내역 목록(누르면 금액·카테고리·메모·날짜 수정), 카드사·토스 **CSV·엑셀(.xlsx)** 파일 자동 인식(UTF-8 · EUC-KR, 신한카드 양식은 취소 건 제외·할부 표시) |
| 저축 | **저축 항목을 눌러 이름·금액·소유자·메모 수정**(금액은 오른쪽 입력칸에서 바로 고침), `+ 저축 항목 추가`·`✕ 삭제`(확인창), 자동이체 체크리스트, **회수금 기록**(실제 받은 금액·날짜·메모를 추가·수정·삭제하면 합계·남은 금액·진행률이 자동 계산, 총액·월 회수액·시작 월은 '회수 계획'에서 수정) |
| 고정지출 | 주택담보대출 트래커(남은 잔액, 이번 달 원금·이자, 회차표, 조건 수정), 추가 대출, **고정지출 항목을 눌러 이름·금액·메모 수정** + `+ 고정지출 항목 추가`·`✕ 삭제`(확인창), 항목별 비중, **가계부 데이터 불러오기/내보내기** |
| 누가 분석 | **누가 가계부 앱의 엑셀(.xlsx/.xls) 내보내기 파일**을 올려 달마다 쌓아 두고, `[2026년 총정리]`·`[1월]`~`[12월]` 칩으로 **그 달**과 **연간 총정리**를 봅니다. 연간: 연간 수입·지출·순저축, 월별 수입 vs 지출 막대 추이, 연간 카테고리 도넛·막대(합계 100%), 연간 결제자 비중, 월별 요약 표(누르면 그 달로). 월: 그 달 요약, 카테고리·결제자 비중, `[전체]/[입금만]/[출금만]`·검색·카테고리 필터가 있는 내역 목록. 여러 달 파일을 한 번에 올려도 되고, 같은 달은 새 파일로 바뀌며, `이 달 지우기`·`전체 지우기`가 있습니다 |
## 대출 트래커 계산 방식

- 입력값: 대출 원금, 연 이율, 상환 방식(원리금균등/원금균등), 상환 기간(개월), 실행일.
- 실행일**이 속한 달의 다음 달**을 1회차로 보고, 납입일은 실행일의 '일'로 계산합니다.
- 오늘 날짜 기준으로 회차·남은 잔액·누적 원금·누적 이자를 매번 다시 계산합니다.

## 개인정보

이 저장소에는 실제 가계부 금액이나 이름이 들어 있지 않습니다. 기본값은 모두 0원이고,
데이터는 각자 기기에서 불러오기로 채웁니다. 브라우저 저장소를 지우면 입력한 내용도 지워지므로
가끔 **내보내기**로 백업해 두세요.

- 엑셀(.xlsx) 파일을 골랐을 때만 SheetJS(`cdn.sheetjs.com`, 실패하면 jsdelivr·unpkg)를 그때 받아 옵니다. 인터넷이 없거나 막혀 있으면 15초 안에 포기하고 안내 문구와 `[엑셀 다시 읽기]` 버튼을 보여 줍니다. 카드사 파일은 브라우저 안에서만 읽고 어디로도 보내지 않습니다.

실시간 동기화를 켜면 가계부 내용이 Firebase(Firestore)의 `households/{방 코드 해시}` 문서로 올라갑니다.
보안 규칙은 `get`만 허용하고 목록 조회(`list`)·삭제는 막아 두었습니다.
