# 우리 집 살림 · 부부 공동 가계부 (웹앱)

매달 저축 · 고정지출 · 자동이체 · 대출 상환을 한 화면에서 보는 부부 공동 가계부입니다.
HTML 파일 하나로 동작하고, 입력한 내용은 **이 기기의 브라우저(localStorage)에만** 저장됩니다.
서버로 보내는 데이터가 없습니다.

## 아이폰에서 앱처럼 쓰기

1. 아이폰 **사파리**로 이 페이지를 엽니다.
2. 아래쪽 **공유(⬆️) 버튼** → **홈 화면에 추가**를 누릅니다.
3. 이름이 `우리 집 살림`으로 나오는지 확인하고 **추가**를 누릅니다.

홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 뜹니다. 한 번 열어 두면 비행기 모드처럼
네트워크가 없어도 열립니다(서비스 워커가 파일을 기기에 캐시).

## 가계부 데이터 불러오기 / 내보내기

- **고정지출** 탭 맨 아래 `가계부 데이터` 카드에서
  - **불러오기**: `.json` 파일을 골라 지금 이 기기의 가계부를 한 번에 채웁니다.
  - **내보내기**: 지금 상태를 `.json` 파일로 저장합니다(백업·기기 이동용).
- 처음 열면 `한눈에` 화면 위에 `가계부 데이터 불러오기` 카드가 보입니다.
- 빈 화면에서 시작하므로, 쓰던 가계부가 있다면 내보낸 파일을 그대로 불러오면 됩니다.
- 입금(수입) 내역은 `한눈에` 탭의 **+ 입금 추가**로 넣습니다. 처음에는 비어 있고, 넣는 만큼 여윳돈이 계산됩니다.

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 한눈에 | **이번 달 여윳돈**(총 입금 − 고정지출 − 월 저축, 변동지출까지 빼면 최종 남는 돈), **입금 내역 추가·수정·삭제**, 월 저축 · 고정지출 · 변동지출 요약, 비율 도넛·막대, 곳간 기준선 초과분 계산기, 대출 잔액 요약, 자동이체·회수금 진행 |
| 변동지출 | 빠른 입력, 내역 목록(누르면 금액·카테고리·메모·날짜 수정), 카드사·토스 CSV 붙여넣기/파일 자동 인식(UTF-8 · EUC-KR) |
| 저축 | 저축 항목 금액 수정, 자동이체 체크리스트, 회수금 회차 트래커(총액·월 금액·회차·시작 월 수정 가능) |
| 고정지출 | 주택담보대출 트래커(남은 잔액, 이번 달 원금·이자, 회차표, 조건 수정), 추가 대출, 고정지출 항목, **가계부 데이터 불러오기/내보내기** |

## 대출 트래커 계산 방식

- 입력값: 대출 원금, 연 이율, 상환 방식(원리금균등/원금균등), 상환 기간(개월), 실행일.
- 실행일**이 속한 달의 다음 달**을 1회차로 보고, 납입일은 실행일의 '일'로 계산합니다.
- 오늘 날짜 기준으로 회차·남은 잔액·누적 원금·누적 이자를 매번 다시 계산합니다.

## 개인정보

이 저장소에는 실제 가계부 금액이나 이름이 들어 있지 않습니다. 기본값은 모두 0원이고,
데이터는 각자 기기에서 불러오기로 채웁니다. 브라우저 저장소를 지우면 입력한 내용도 지워지므로
가끔 **내보내기**로 백업해 두세요.
